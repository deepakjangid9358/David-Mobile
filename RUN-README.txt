# David Mobile - Ready-to-Run Package

## First time
1. Install Node.js LTS from https://nodejs.org/
2. Double-click `SETUP-DAVID-MOBILE.bat`
3. When setup finishes, double-click `START-DAVID-MOBILE.bat`
4. Open the localhost URL shown in the terminal.

## Production build
Double-click `BUILD-DAVID-MOBILE.bat`.
The production files will be created in `dist`.

## Important
This package does not contain a Node.js installer itself. Node.js must be installed once on Windows.
Do not put private API keys into public GitHub repositories.
