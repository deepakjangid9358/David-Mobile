GITHUB PAGES DEPLOYMENT

1. Upload/commit this project to:
   https://github.com/deepakjangid9358/David-Mobile

2. Make sure the default branch is "main".

3. Go to:
   Settings -> Pages

4. Under Build and deployment, select:
   Source: GitHub Actions

5. Go to Actions and wait for "Deploy David Mobile to GitHub Pages" to finish.

6. Your site should be:
   https://deepakjangid9358.github.io/David-Mobile/

IMPORTANT:
- GitHub Pages hosts the frontend only.
- Firebase/API keys and cloud database/auth still need correct production configuration.
- Do not commit private secrets to GitHub.
